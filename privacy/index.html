حریم خصوصی؛ داده‌ها در این وب‌سایت چگونه استفاده می‌شوند؟

این نسخه از وب‌سایت یک مجموعه صفحه ایستا روی GitHub Pages است. در کد سایت فرم حساب، پرداخت، نظر یا سامانه تحلیل رفتار سفارشی قرار ندارد.

ابزارهای این سایت در مرورگر اجرا می‌شوند؛ اما میزبان و مقصد لینک خارجی می‌توانند سیاست‌های مستقل داشته باشند.

داده‌های واردشده در ابزارها

جستجوی مطالب از محتوای همین صفحه استفاده می‌کند. جداکننده URL و محاسبه‌گر ضریب نیز ورودی را در مرورگر پردازش می‌کنند و کد آن‌ها درخواست شبکه برای ارسال این داده‌ها ندارد.

در این نسخه، کد سفارشی برای ذخیره ورودی در کوکی یا حافظه مرورگر وجود ندارد. این توضیح درباره کد پروژه است و درباره همه رفتارهای مرورگر یا زیرساخت میزبانی ادعا نمی‌کند.

میزبانی و درخواست‌های صفحه

هنگام باز کردن سایت، مرورگر برای دریافت صفحه، فونت و تصویر به میزبان درخواست می‌فرستد. اطلاعات فنی اتصال ممکن است طبق سیاست سرویس میزبانی پردازش شود.

برای اطلاعات مربوط به خود سرویس، سیاست حریم خصوصی GitHub را مطالعه کنید. این سایت به گزارش‌های داخلی کاربران GitHub یا سوابق شخصی شما دسترسی ندارد.

لینک خارجی و گزارش عمومی

وقتی لینک خارجی را باز می‌کنید، سیاست همان مقصد اعمال می‌شود. ثبت Issue در GitHub محتوای گزارش را عمومی می‌کند؛ اطلاعات حساس را در گزارش درج نکنید.

تغییرات این صفحه

اگر در آینده فرم، آمارگیر یا قابلیت ذخیره داده اضافه شود، توضیح این صفحه نیز باید با کد جدید هماهنگ شود. تاریخ بازبینی این نسخه در بالای صفحه درج شده است.
