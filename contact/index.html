تماس و گزارش خطا؛ کمک به اصلاح راهنماها

برای گزارش خطای متن، لینک خراب یا پیشنهاد یک موضوع، می‌توانید از بخش Issues مخزن عمومی پروژه استفاده کنید. این مسیر برای پیگیری محتوای همین وب‌سایت است.

آنچه باید بدانید

گزارش GitHub عمومی است؛ رمز، شماره کارت، مدارک هویتی و اطلاعات خصوصی را در آن منتشر نکنید.

چطور گزارش مفید بنویسیم؟

عنوان کوتاه و آدرس دقیق صفحه را بنویسید. مشخص کنید مشکل در کدام بخش است، چه نتیجه‌ای انتظار داشتید و چه اصلاحی پیشنهاد می‌کنید.

  • آدرس کامل صفحه و عنوان بخش
  • توضیح کوتاه مشکل یا لینک خراب
  • در صورت نیاز، منبع اولیه اصلاح
  • تصویر با حذف کامل اطلاعات شخصی

این مسیر برای چه کاری نیست؟

ما به حساب، موجودی یا تراکنش هیچ سایت بازی دسترسی نداریم. درخواست برداشت، بازیابی حساب یا اختلاف پرداخت باید از مسیر مربوط به همان خدمت پیگیری شود.

در نسخه فعلی، فرم ارسال خصوصی یا سامانه تیکت وجود ندارد. از انتشار داده شخصی در مخزن عمومی خودداری کنید.

گزارش بدون حساب GitHub

اگر امکان ثبت Issue ندارید، می‌توانید کد و تاریخچه پروژه را به‌صورت عمومی ببینید. برای ثبت گزارش در GitHub ممکن است حساب کاربری لازم باشد؛ این وب‌سایت فرم جایگزین یا زمان پاسخ تضمینی اعلام نمی‌کند.
